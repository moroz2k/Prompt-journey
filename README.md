# Мой путь в LLM (Prompt Journey)

Этот репозиторий — мой дневник обучения работе с большими языковыми моделями (LLM). 
Я прохожу путь от базовых промптов до создания автономных ИИ-агентов с доступом к инструментам.

## 🛠️ Что уже реализовано (по дням)

*   **День 3:** Первое подключение к локальной модели (Qwen) через API.
*   **День 4:** Работа с ролями и системными промптами.
*   **День 5:** Цепочки рассуждений (Chain-of-Thought) для решения логических задач.
*   **День 6:** Борьба с галлюцинациями (заземление фактов).
*   **День 7–8:** Векторный поиск. Превращение текста в эмбеддинги.
*   **День 9:** Мини-RAG (поиск + генерация).
*   **День 10–11:** Работа с векторной базой данных ChromaDB (сохранение на диск).
*   **День 12–13:** Первый ИИ-агент с Function Calling (выбор между калькулятором и поиском по базе).

## 🚀 Технологии
*   Python
*   LM Studio (Qwen 2.5 7B)
*   ChromaDB
*   Sentence-Transformers
*   OpenAI Python Client
