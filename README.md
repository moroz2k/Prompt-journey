Этот репозиторий — мой дневник обучения работе с большими языковыми моделями (LLM).

  ## 🏆 Главный проект: Диалоговый RAG-бот по PDF
Файл **`pdf_rag_chat.py`** — это финальный результат моей работы на данный момент. 
Это полноценный консольный чат-бот, который:
1. Читает PDF-документ (в репозитории приложен пример `test.pdf`).
2. Нарезает его на куски (chunking) с перекрытием.
3. Загружает куски в векторную базу данных (ChromaDB).
4. Ищет ответы по смыслу, используя модель эмбеддингов.
5. Генерирует ответ с помощью локальной LLM (Qwen 2.5 7B) и **помнит историю диалога**.

  ### 🚀 Как запустить главный проект
1. Установите зависимости:
   ```bash
   pip install chromadb openai pypdf sentence-transformers
2. Установите и запустите LM Studio, скачайте модель Qwen 2.5 7B Instruct и запустите локальный сервер (Developer -> Start Server).

3. В файле pdf_rag_chat.py проверьте путь к PDF-файлу (переменная PDF_PATH).

4. Запустите скрипт:
   ```bash
   python pdf_rag_chat.py
